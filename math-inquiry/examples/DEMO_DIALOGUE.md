# 分式复习模拟对话

这段对话是为项目编写的模拟演示，使用自拟题目，不是真实学生记录，也不代表已验证的教学效果。它展示如何在新任务中检查学生的独立表现，以及如何如实记录提示。

学生首次自查先使用[学生任务页](STUDENT_TASKS.md)。核对数学内容可读[参考解](DEMO_PACK.md)。

## 第一次作答

**学生：** `(x²−9)/(x−3)` 约分后是 `x+3`，所以 x 可以是任意实数。

**AI：** 你完成了化简。先检查原式：当 x=3 时，原来的分母是多少？

**学生：** 是 0，所以原式不允许 x=3。我应当补上 x≠3。

## 换一道题独立尝试

**AI：** 现在试一道新题：化简 `(x²−16)/(x²−4x)`，并写出原式有意义的条件。我先不提示。

**学生：** 我得到 `(x+4)/x`，条件是 x≠0。

**AI：** 化简成立。你写出了一个限制；把原分母写成 `x(x−4)` 后，还有哪个取值会使它为零？

**学生：** 还要排除 4，因此原式的条件是 x≠0 且 x≠4。

## 记录这次实际发生的事

**AI：** 这次两道题的代数化简是你独立完成的；原式的取值限制都在提示后补全。下一次可以换一道未讲过的题，先保留你的完整作答，再看能否自己写全限制。

| 观察项目 | 本轮记录 |
|---|---|
| 两道题的化简 | 独立完成 |
| 第一题排除 x=3 | 提示后补充 |
| 第二题排除 x=0 | 独立写出 |
| 第二题排除 x=4 | 提示后补充 |
| 再次独立写全限制 | 尚未检查 |
| 过一段时间还能否独立完成 | 尚未检查 |

新题中的错误提供了继续学习的具体方向。这次对话可以结束在清楚的过程记录上；后续用新任务复查，不把一句“懂了”或一次修正当作长期掌握。
