# 验证入口与证据边界

研究包回归的[实际输出摘要](工程核验.json)与教学测试分开保存。在仓库根目录执行（Python 3.9+）：

```sh
python3 tests/verify_public.py
```

验证文件摘要与白名单、相对链接、UTF-8、重新生成的原创 JSONL、两份 Markdown、SQLite 各表全部值、只读演示和资料缺失时的错误。研究资料不随候选分发；持有解压后原包的维护者可另外运行：

```sh
python3 tests/verify_research.py "build/imported/junior_math_knowledge_base_v1.1 2"
```

研究验证执行七条原 README 命令，按结果与状态断言；比较新旧库全表全视图、只读摘要、输入不变；注入错误引用和调换记录顺序。结构通过不改变 verified/study_ready。

**数学审核**单独检查 [4 组原创参考解](../examples/DEMO_PACK.md)：零解和非零解覆盖完整；两道分式按原分母排除全部零点；情境时间含两端且可连续；两种表示恒等、最小值与取等点在给定区间均可达。以代数推导为主，不用抽样代替证明。本次为项目整理时核算，不是外部教师认证或全研究库复审。

**平台与学习效果**见[评估规定](../evals/README.md)和[运行状态](../evals/run-status.md)。工程环境能读取文件和运行命令，不代表模型在每个独立对话中能正确引导。没有真实学生试课、延迟复查或平台兼容率。
