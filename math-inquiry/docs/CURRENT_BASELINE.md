# 当前研究数据与检查边界

统计对象是项目发起人提供的 V1.1 ZIP；实际文件名虽少了 (1)，SHA-256 与交接清单一致。本页介绍私有研究基础，不是公开包的随附数量。

原包对应证据为 data 中各 JSONL、database/math_kb.sqlite、reports/coverage_report.md 与 reports/中考真题处理报告.md。

## 本轮确认了什么

JSONL 与 SQLite 的指定表内容、映射、来源文件存在性和状态字段均完成了结构核查。SQLite 完整性与外键检查通过；工作副本中本地文档链接可解析。

交接审计时七条查询有一条失败。候选版已修复例题查询，并以显式输入和新输出重建 14 张表、6 个视图。按全列和重复次数与基线核对，唯一允许的差异是六册 source_file 本地路径。[验证方法](verification.md)。

307 道标例与 21 个可练中考题的“已核”归属原项目状态。本轮检查了状态、相关字段和文件存在性，没有重新独立逐题验证全部数学内容。

## 范围与下一步

节点年级为七、八、九年级；没有高中数据。统计主题虽使用“统计与概率”名称，实际节点为统计内容，概率知识体系尚未建立。

九上与九下的版本证据和章号体系不同，应保留来源与版本身份；不能写成确定同版的一套完整教材。原项目尚保留六册覆盖复核及一次扫描例题召回复核，共七个未结项。

已有题目 methods 标签和方法类概念，但一般数学思想尚无独立实体与专门映射。323 道任务中的 183 种 methods 字面名称不等于 183 种数学思想。222 个概念中，20 个有直觉解释、39 个有易错说明、118 个有条件字段；应按演示主题补充实质内容，不机械填满。

平台体验、模型评估与真实学生效果尚未由本轮验证。公开文档保持这几类证据的区别。
