# Codex 与 WorkBuddy 的使用路径

本页沿用交接包 2026-11-18 附的官方资料指引；本轮未重新核验外部页面或平台版本。Codex 当前开发会话实际读取了本地文件并运行 Python 工具；未执行独立学习会话测试，WorkBuddy 未实测。启动时仍需核对实际读到的文件。

## 共用起点

准备工作目录，放入说明、所选提示词和相关学习资料。先执行资料核对，再开始四场景中的一个。演示参考答案给 AI 使用，学生先在任务页独立作答。

读取文件并不等于已经建立自动检索、长期学习档案或提醒。数据处理方式取决于平台和配置，不能从“文件在电脑上”推断全部推理都在本机。

## Codex

官方文档说明 Codex 会在工作开始前读取适用的 AGENTS.md，并按全局与目录层次组合指令。因此建议把项目约定放在仓库根目录，再在任务中明确学习场景。[官方依据](https://learn.chatgpt.com/docs/agent-configuration/agents-md)

在能够读取项目文件的环境中打开本目录，要求 AI 确认实际读到的项目约定，再指定场景与资料。可以发送：

~~~text
这次是数学学习任务。
请读取 prompts/COMMON.md、prompts/A_STUCK.md
和 examples/DEMO_PACK.md。
先核对你读到的资料与来源类型，再按卡题场景帮助我。
本次只查阅学习资料，不修改知识库。
我的题目、尝试和卡点如下：【填写】
~~~

读不到文件时改用上传或粘贴，不把读取失败解释为教材中不存在这个概念。

## WorkBuddy

官方文档提供工作目录选择、文件引用与上传入口，并说明任务会在所选目录中读取和保存文件。[官方依据](https://www.workbuddy.ai/docs/zh/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar)

新建任务后选择资料目录，引用或上传公共约定、所选提示词与资料。明确要求先核对已读文件，再开始学习。上面的启动文本可按实际文件位置使用。

本页不假定 WorkBuddy 自动读取 AGENTS.md，请显式引用必要约定。题目依赖图片时先确认当前模型支持图片输入；能力不足时补充文字条件或换到可读图片的环境。

## 怎样记录平台验证

实际测试时记录平台与版本、模型、日期、文件、权限、提示词和完整输出。至少完成资料核对与四场景各一个任务，再报告具体结果。

未观察到的能力记未验证；图像等能力不可用时记 blocked，不记通过。详细执行方法见 [测试说明](../evals/README.md)。
