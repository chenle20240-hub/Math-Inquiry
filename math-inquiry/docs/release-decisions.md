# 发布范围与待决项

本版的“候选”仅表示适合交给发起人作公开审查，不等于已经授权、上传或公开。第三方资料默认不选取，连只含元数据的整行也不自动放行。

| 来源 | 候选内容与理由 | 决策 |
|---|---|---|
| 发起人提供的最新 README、交接草稿、学生 SOP 的流程整理 | 项目介绍、四场景提示词、学生与家长接入说明、评估设计、原创示意图；只列入逐文件清单的整理稿，不复制 PDF | 本地候选；署名及内容许可待确认 |
| 交接包明确标作自拟的 A–D 和两个条件变化任务 | 独立 DEMO 命名空间；本地核对推导后生成数据库和读者页 | 本地候选；不授予教材身份 |
| 研究包原查询及 V1.1 数据结构；此次编写的其余工具 | 查询兼容原参数；schema 仅含结构，代码不携带教材内容 | 本地候选；原有代码权属及通知待确认 |
| 私有教材、题干、答案、解法、页图、试卷、Word/PDF/OMML、段落证据、真实学生记录 | 无确认的公开依据 | 排除全部原件及 JSONL、SQLite payload、curation、Markdown 副本；不导出研究数据库 |
| 研究基线的数量、状态说明及评估夹具的少量公开候选 ID/状态 | 仅作来源边界说明，未复制试题 | 不据此声称教材库随附、均可练或全部数学正确 |

**文件边界：** [逐文件清单](../release/files.json)中的源文本/图形及清单本身；另生成三份 JSONL、一份演示 SQLite 以及学生页、参考页。未列入的文件不复制。变更文件内容导致摘要不符时停止导出。

**字段边界：** [原创源记录](../catalog/demo.json)只允许 concepts 的 id/origin/title/condition/thought/action，tasks 的 id/origin/scene/title/problem/start/solution，以及 links 的 id/origin/task/concept/reason。逐条 ID 清单与字段校验见[导出规则](../scripts/public_demo.py)。origin 只能为 original_demo；solution 仅在参考页与明示核对模式展示。没有通用 payload 字段。

**公开前需要发起人决定：** 目标 GitHub owner/repo、可见性、写入授权；确认候选文件的署名、代码（含原工具/结构）的分发依据，以及原创内容是否采用允许商业复用的许可。详见[许可方案](../LICENSE_POLICY.md)。即使这些事项确认，也不自动扩大第三方资料范围。家长原方案日后单独接入，不阻碍当前候选交付。
