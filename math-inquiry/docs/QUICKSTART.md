# 开始第一次数学学习

这个体验使用本项目自拟资料，不需要取得原教材或试卷。最快的入口是[学生任务页](../examples/STUDENT_TASKS.md)：选 B，先写自己的化简和条件，再请 AI 核对。

也可以从仓库根目录用 Python 3.9+ 离线读取同样的任务，不需安装依赖。前两条命令不会输出参考解；第三条只在已写下第一稿之后运行：

```sh
python3 scripts/demo.py
python3 scripts/demo.py DEMO-B01
python3 scripts/demo.py DEMO-B01 --after-attempt
```

命令行是只读题卡，不是聊天机器人；不接入模型，也不自动保存学习记录。

## 1 让 AI 读到资料

在支持读取工作目录的平台中，将本仓库目录设为工作区。如果只能上传文件，就上传本次需要的提示词和演示资料；也可以粘贴必要内容。

请 AI 读取 prompts/COMMON.md、选定的场景模板和 examples/DEMO_PACK.md。参考资料含答案，独立自查的学生先不阅读参考解，直接打开 [学生任务](../examples/STUDENT_TASKS.md)。

用 [资料核对提示词](../prompts/SOURCE_CHECK.md) 检查它是否真的读到了内容。让它给一个相关条目的标题和一个条件，不先给自查题的解法。自己核对后再开始。

## 2 选今天的一个场景

| 需要 | 模板 |
|---|---|
| 卡在一道题 | [做题卡住](../prompts/A_STUCK.md) |
| 回顾或检查旧知识 | [复习](../prompts/B_REVIEW.md) |
| 预习新课 | [预习](../prompts/C_PREVIEW.md) |
| 理解为什么用某方法 | [数学思维](../prompts/D_THINKING.md) |

填入年级、已学内容、题目、已有尝试与卡点。没思路可以如实写，不需要先编一个过程。

## 3 做一步 再看需要什么帮助

按照 AI 的第一个任务写出自己的计算或理由。卡住就要一个提示；仍不会，可以要求示范关键一步。把自己的第一稿留下，修正在下一行写。

原题完成后，需要检验时再换一道未讲过的新题，让 AI 等你作答后再给反馈。

## 4 用一句具体记录收尾

例如：“化简是我独立完成的；原式限制是在提醒后补上的。”

使用 [学习记录](LEARNING_RECORD.md) 保存题目、第一次尝试、提示和修正。下次可以把记录贴回对话。只有实际保存了文件，才算完成保存。

具体平台操作见 [平台说明](PLATFORM_GUIDE.md)。想看完整交流，作答后可以阅读 [模拟对话](../examples/DEMO_DIALOGUE.md)。
