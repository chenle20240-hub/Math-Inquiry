# 选择今天的学习场景

第一次使用，先完成 [资料读取核对](SOURCE_CHECK.md)。每次选择下面一个场景，填写【】中的信息，再把完整提示词发给 AI。

| 我今天需要 | 完整提示词 |
|---|---|
| 一道题卡住了，或者不知道哪里错了 | [A 做题卡住](A_STUCK.md) |
| 回顾旧知识、独立自查或复盘错题 | [B 复习旧知识](B_REVIEW.md) |
| 为新课建立一个起点 | [C 预习新课](C_PREVIEW.md) |
| 理解为什么选择某种方法 | [D 探讨数学思维](D_THINKING.md) |

四份模板按用户提供的学生 SOP 第 10—13 页整理。共用行为见 [公共约定](COMMON.md)；在支持读取工作区的环境中，可以让 AI 读取公共约定与所选模板。

## 对话不顺时怎样调整

- 一直追问却没有帮助：“请示范我卡住的关键一步，说明依据，再留一步给我。”
- 一次讲太多：“请停在这一步，只解释用了什么条件。”
- 想知道自己是否能独立完成：“换一道未讲过的新题，等我写完再提示。”
- 找不到所引资料：“请把实际读到的内容与补充解释分开，给出可核对位置。”
- 题图不清楚：“请先列出看得清的条件，指出哪处需要补图。”

没有可读教材时仍可使用本项目的 [原创任务](../examples/STUDENT_TASKS.md)，但应说明正在用自拟演示，不把说明编成教材引文。
